# Sciobraille 1.3.0

- Added saved Automatic, Front side only, and Reverse side only recognition
  modes. Automatic checks both orientations and selects the stronger raw result.
- Added accessible in-app photo guidance with do/avoid recommendations and TTS.
- Added dynamic scan-quality advice based on detections, confidence, distance,
  tilt, and selected orientation.
- Added annotated detection images with labels, confidence, and sharing.
- Added copy/share actions for Unicode Braille output.
- Switched Braille gallery selection to Android Photo Picker.
- Separated private model contribution from explicit public dataset consent.
- Kept recognition, history, LMS progress, and core tools offline-first with no
  account requirement.
