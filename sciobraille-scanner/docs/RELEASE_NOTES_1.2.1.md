# Sciobraille 1.2.1

- Added an optional **Improve the model** action after a processed scan.
- Added reviewable ground-truth text and scan-condition notes.
- Added explicit content, age/authority, and training-use consent checks.
- Contributions remain offline until the user chooses a recipient in Android's
  share sheet; no scans are uploaded automatically.
- Contribution packages include the model-facing image, prediction metadata,
  model hash, corrected transcript, and a random contribution ID.
- Added a private validation/quarantine importer for received packages.
- Updated the privacy policy and Play Data Safety guidance.
