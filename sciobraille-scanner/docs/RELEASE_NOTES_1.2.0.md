# Sciobraille 1.2.0

- Braille scanning now runs completely on-device with the bundled V2 model.
- Camera frames and gallery images no longer require a laptop or FastAPI server.
- Reverse-side horizontal flipping is evaluated locally, with automatic
  front-side orientation selection when clearly better.
- Full local Braille learning curriculum is available without a nonfunctional
  paywall.
- Learning progress, milestones, certificates, settings, and scan history stay
  on the device.
- Added an in-app privacy summary and public privacy-policy link.
- Updated camera permission handling, backup protections, and Android 16
  orientation behavior.
