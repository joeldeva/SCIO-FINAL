# Dataset Information

## Source
Roboflow Universe — Braille Detection Dataset
URL: https://universe.roboflow.com/braille-lq5eh/braille-detection

## Details
- Total Training Images: 1016
- Validation Images: 209
- Test Images: 50+
- Classes: 26 (A-Z English Braille letters)
- Format: YOLOv8 (TXT annotations + YAML config)
- License: CC BY 4.0

## Preprocessing
- Auto-orientation of pixel data
- Resize to 640x640
- No augmentation applied

## Split
- Train: 80%
- Validation: 16%
- Test: 4%
